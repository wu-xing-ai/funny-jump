# 🎮 趣味游戏 · 跳跳大冒险

> 一个零依赖的单文件 HTML 跑酷小游戏 —— 控制呆萌的豆豆跳过障碍、收集星星，活得越久分越高！

**▶ 在线游玩：<https://jump.wuxinw.dpdns.org>**（备用：<https://funny-jump.pages.dev>）

手机竖屏也能玩（画面自动旋转 90°），支持触屏与刘海屏。

---

## ✨ 特色

- 🎨 卡通画风：四层视差滚动背景 + 昼夜循环（白天→黄昏→星空→黎明）
- 🔊 WebAudio 实时合成的搞笑音效：弹簧“啵嘤~”、悲伤长号、胜利小旋律……
- ⚡ 速度持续提升，上限 ×2.5
- 🏆 排行榜：可留名 / 匿名 / 写备注；本地保存，可选接入云端全服共享榜
- 📱 手机端适配：竖屏旋转玩法、安全区避让、一键全屏
- 💥 3000 分后解锁 4 种新障碍：悬浮闸门、激光柱、史莱姆、UFO

## 🕹 操作

| 平台 | 操作 |
|---|---|
| 键盘 | <kbd>空格</kbd>/<kbd>↑</kbd>/<kbd>W</kbd> 跳跃（长按跳更高）；<kbd>P</kbd> 暂停；<kbd>R</kbd> 重开；<kbd>M</kbd> 静音 |
| 触屏 | 点屏幕跳跃（按住更高）；空中再点一下＝**二段跳** |

💡 小贴士：头顶的蜜蜂别硬跳——贴地跑最稳，高手可以用二段跳从它上面飞过去！

## 🚧 障碍图鉴

| 障碍 | 解锁分数 | 通过方式 |
|---|---|---|
| 🌵 仙人掌 / 🪵 原木 | 开局 / 120 | 跳过 |
| ⚡ 刺球 | 550 | 跳过 |
| 🐝 蜜蜂 | 380 | 贴地跑过，或二段跳飞越 |
| 🟪 悬浮闸门 | 3000 | 别跳！贴地钻缝 |
| 🔴 激光柱 | 3000 | 趁熄灭时通过（警告闪烁后发射） |
| 🟢 史莱姆 | 3000 | 正常跳过（它只是想卖萌） |
| 🛸 UFO | 3000 | 看相位：低位别跑，高位贴地溜过或二段跳飞越 |

⭐ 吃到星星 +15 分，每 100 分有欢呼播报。

## 🚀 运行

零依赖：**直接双击打开 `index.html` 就能玩。**

## 📦 部署与打包

部署到 Cloudflare Pages、开启云端排行榜、GitHub 自动部署、打包成 Windows/iOS/安卓 App 等详细教程，见 **[DEPLOY.md](DEPLOY.md)**。

## 📁 目录结构

```text
index.html        游戏本体（全部逻辑都在这一个文件里）
config.js         配置文件：玩家名单、云端排行榜接口地址
worker.js         云端排行榜接口（/scores，与游戏页面同域）
wrangler.toml     部署配置（含 KV 数据库绑定，重新部署不丢数据）
.github/workflows 自动部署工作流（push 到 main 即发布）
DEPLOY.md         部署与打包详细教程
```
